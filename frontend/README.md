# Frontend

This is the active React/Vite application.

- `src/components`: reusable layout and UI components
- `src/pages`: route-level screens
- `src/providers`: authentication and theme state
- `src/hooks`: shared React hooks
- `src/lib`: API client, formatting, insights, and utilities
- `scripts`: build helpers

Run `npm run dev` from this directory for development. `npm run build` writes the production bundle to `../backend/static`.
